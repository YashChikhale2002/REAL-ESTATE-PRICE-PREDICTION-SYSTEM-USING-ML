# Real Estate Price Prediction System

A machine learning-based web application for predicting real estate prices using various property features.

## Features
- Train ML models (Linear Regression, Random Forest, XGBoost)
- Predict property prices based on features
- SQLite3 database for storing properties and predictions
- Web interface built with Flask
- Historical prediction tracking
